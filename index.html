AlgoRhythm

Interaktywna platforma do nauki algorytmów i struktur danych

Frontend Backend

📌 O projekcie

AlgoRhythm to interaktywna platforma e-learningowa umożliwiająca naukę algorytmów i struktur danych poprzez praktykę. System pozwala rozwiązywać zadania programistyczne, analizować wydajność kodu oraz korzystać z materiałów teoretycznych i wizualizacji.

🎯 Cel projektu

Celem projektu było stworzenie nowoczesnej aplikacji webowej łączącej teorię z praktyką. Użytkownicy mogą przechodzić kursy, rozwiązywać zadania i śledzić swoje postępy.

⚙️ Technologie

  • Backend: ASP.NET Core
  • Frontend: React + TypeScript
  • Baza danych: Microsoft SQL Server
  • DevOps: Docker + Azure

🧠 Funkcjonalności

  • Rozwiązywanie zadań programistycznych
  • Automatyczne testy kodu
  • Wizualizacje algorytmów
  • Kursy i materiały edukacyjne
  • System postępów i osiągnięć
  • Panel administratora

🔐 Bezpieczeństwo

Kod użytkownika wykonywany jest w izolowanym środowisku (kontenery Docker), co zapewnia bezpieczeństwo i ochronę danych.
